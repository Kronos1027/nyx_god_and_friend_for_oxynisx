# Nyx / Oxynisx

Repositório privado autorizado para desenvolvimento e recuperação da assistente local Nyx para Windows.

## Estado

O aplicativo está em desenvolvimento. Não é AGI; qualidade e capacidade dependem do modelo local e das ferramentas. A meta inclui interface nativa modular, companheira Oxynisx, voz, agentes, agenda, aprendizado com fontes e evolução avaliada.

## Política de dados

Código e documentação podem ser versionados. Não enviar chaves, tokens, arquivos .env, histórico de conversas, bancos SQLite, capturas de tela ou logs em texto claro. Backups pessoais devem ser criptografados antes do envio, com chave de recuperação guardada separadamente. O primeiro commit apenas inicializa o repositório; não representa backup dos dados locais.

## Evolução

Observar → formular hipótese → propor habilidade → simular estrutura → testar comportamento em ambiente isolado → comparar métricas → aprovar versão → monitorar → reverter se necessário. A implementação inicial armazena notas com fontes e simula planos declarativos sem executar código. Execução isolada de código e promoção automática continuam pendentes.
